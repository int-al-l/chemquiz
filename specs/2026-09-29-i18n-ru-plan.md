# Russian Translation (RU / EN) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every text a user sees — interface, cards and decks, server errors, emails — in Russian or English; users pick the language in the app, the teacher picks it for a class game.

**Architecture:** The server localises card/deck texts, error messages and emails by the request's language (`Accept-Language`, or a live game's `lang`); Russian card texts live in a hand-edited `backend/content_ru.py`. The frontend gets a small `src/i18n/` module (dictionaries, `LanguageProvider`, `useT()`, plurals via `Intl.PluralRules`) and sends the chosen language with every request.

**Tech Stack:** FastAPI + SQLAlchemy 2.0 + SQLite (pytest); React + react-router + Vite (vitest, eslint). No new dependencies.

**Spec:** [`specs/2026-09-29-i18n-ru-design.md`](2026-09-29-i18n-ru-design.md)

## Global Constraints

- Branch `nik/i18n-ru`; never commit to `main`; never edit or commit `docs/` or `src/demo/data.json` (generated by CI).
- Do not edit `backend/seed_data.py` (generated by `catalog/synthware/build.py`). Russian card texts go only in `backend/content_ru.py`.
- Languages are exactly `"en"` and `"ru"`. Anything else means English.
- Request language: live game's `lang` first; else `Accept-Language` starting with `ru` (case-insensitive) → `"ru"`; else `"en"`.
- A missing Russian text falls back to English — never an empty string, never a raw key on screen.
- English texts stay exactly as they are today (existing tests and screens must not change in English).
- Error response body: `{"detail": "<text in the language>", "code": "<message key>"}`; status codes unchanged.
- Frontend language: `localStorage["chemquiz.lang"]` → else `navigator.language` starting with `ru` → `"ru"` → else `"en"`. `<html lang>` follows it.
- Class game: the teacher's choice at room creation (`lang` on `live_games`); board and phones follow it; phones have no switch.
- Plurals through `Intl.PluralRules`: English keys `one`/`other`; Russian `one`/`few`/`many`/`other`.
- No sentence built by concatenating translated fragments; whole sentences with `{name}` placeholders.
- Russian lab terms: use established ones (холодильник Либиха, колба Бунзена, делительная воронка, аллонж, …).
- Backend commands: `cd backend && python3 -m pytest -q`. Frontend: `npm run lint && npm test && npm run build`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```python
"""The language of a request, and errors that know how to say themselves.

A request is in Russian when its Accept-Language header starts with `ru`;
a live game overrides that with its own `lang`. Everything else is English.
"""

from __future__ import annotations

from typing import Any, Optional

from fastapi import Request
from fastapi.responses import JSONResponse

from . import messages

LANGS = ("en", "ru")


def normalize_lang(value: Optional[str]) -> str:
    """"ru-RU,ru;q=0.9" -> "ru"; anything not Russian first -> "en"."""
    first = (value or "").split(",")[0].strip().lower()
    return "ru" if first.startswith("ru") else "en"


def request_lang(request: Request) -> str:
    """FastAPI dependency: the language the client asked for."""
    return normalize_lang(request.headers.get("accept-language"))


def localized(obj: Any, field: str, lang: str) -> Optional[str]:
    """`obj.<field>_ru` in Russian when it is set, otherwise `obj.<field>`."""
    if lang == "ru":
        value = getattr(obj, f"{field}_ru", None)
        if value:
            return value
    return getattr(obj, field)


class AppError(Exception):
    """A request the site refuses, with a message key rather than a text.

    `lang` may be set before raising (a live game's language); otherwise the
    exception handler uses the request's language.
    """

    def __init__(self, key: str, status: int = 409, **values):
        super().__init__(messages.text(key, "en", **values))
        self.key = key
        self.status = status
        self.values = values
        self.lang: Optional[str] = None

    def response(self, lang: str) -> JSONResponse:
        return JSONResponse(
            status_code=self.status,
            content={"detail": messages.text(self.key, lang, **self.values), "code": self.key},
        )
```

```jsx
/**
 * The interface language: which one, and the texts in it.
 *
 * The choice is kept on the device (localStorage) and, until a person makes
 * one, follows the browser. The API client is told too, so the server sends
 * card names and errors in the same language.
 */
import { createContext, useCallback, useContext, useEffect, useMemo, useState } from "react";

import { setRequestLanguage } from "../api/client";
import en from "./en";
import ru from "./ru";

export const LANGUAGES = ["en", "ru"];
const DICTIONARIES = { en, ru };
const STORAGE_KEY = "chemquiz.lang";

export function detectLanguage(stored, browser) {
  if (LANGUAGES.includes(stored)) return stored;
  return (browser || "").toLowerCase().startsWith("ru") ? "ru" : "en";
}

function readStored() {
  try {
    return window.localStorage.getItem(STORAGE_KEY);
  } catch {
    return null;
  }
}

function writeStored(lang) {
  try {
    window.localStorage.setItem(STORAGE_KEY, lang);
  } catch {
    /* private mode: the choice lasts until the tab closes */
  }
}

export function translate(lang, key, values = {}) {
  const entry = DICTIONARIES[lang]?.[key] ?? en[key];
  if (entry === undefined) return key;
  let text = entry;
  if (typeof entry === "object") {
    const known = DICTIONARIES[lang]?.[key] ? lang : "en";
    const form = new Intl.PluralRules(known).select(values.n ?? 0);
    text = entry[form] ?? entry.other;
  }
  return text.replace(/\{(\w+)\}/g, (match, name) => (name in values ? String(values[name]) : match));
}

const LanguageContext = createContext({ lang: "en", setLang: () => {} });

export function LanguageProvider({ children }) {
  // Read synchronously, so the very first requests already carry the language.
  const [lang, setLangState] = useState(() => {
    const initial = detectLanguage(readStored(), window.navigator?.language);
    setRequestLanguage(initial);
    return initial;
  });

  const setLang = useCallback((next) => {
    if (!LANGUAGES.includes(next)) return;
    setRequestLanguage(next);
    writeStored(next);
    setLangState(next);
  }, []);

  useEffect(() => {
    document.documentElement.lang = lang;
  }, [lang]);

  const value = useMemo(() => ({ lang, setLang }), [lang, setLang]);
  return <LanguageContext.Provider value={value}>{children}</LanguageContext.Provider>;
}

/** A part of the page in a fixed language (a class game in the teacher's). */
export function LanguageScope({ lang, children }) {
  const outer = useContext(LanguageContext);
  const value = useMemo(
    () => ({ lang: LANGUAGES.includes(lang) ? lang : outer.lang, setLang: outer.setLang }),
    [lang, outer],
  );
  return <LanguageContext.Provider value={value}>{children}</LanguageContext.Provider>;
}

export function useLang() {
  return useContext(LanguageContext);
}

export function useT() {
  const { lang } = useLang();
  return useCallback((key, values) => translate(lang, key, values), [lang]);
}
```
